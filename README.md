# Copilot MCP Demo

A small, dependency-free Python insurance application demonstrating a basic policy and claims workflow.

## Features

- Create an active insurance policy
- Create a claim against an active policy
- Approve a pending claim
- Validate duplicate records, missing policies, inactive policies, and invalid amounts

## Run the demo

Requires Python 3.9 or newer.

```bash
python main.py
```

The example creates a home insurance policy, submits a water-damage claim, and approves it. All data is stored in memory and is lost when the program exits.
